# Album de Figuritas GTA

WebApp creada con HTML y CSS para mostrar un album de figuritas inspirado en Grand Theft Auto.

## Descripcion

El proyecto presenta una pagina principal con estilo Rockstar y acceso a cuatro secciones:

- GTA San Andreas
- GTA Vice City
- GTA IV
- GTA V

Cada seccion contiene figuritas organizadas en una grilla responsive. Las cartas muestran imagen, nombre, categoria e informacion desplegable.

## Funcionalidades

- Pagina principal con fondo Rockstar.
- Botones con estilos inspirados en cada juego.
- Navegacion interna a cada seccion usando enlaces.
- Figuritas con bordes por categoria:
  - Azul: personajes principales.
  - Rojo: antagonistas.
  - Dorado: ciudades o mapas.
- Informacion desplegable en cada figurita.
- Carta rainbow de dato curioso en cada juego.
- Boton dorado con logo de Rockstar para volver a la portada.
- Diseno responsive para celular y PC.

## Como abrir el proyecto

1. Descargar o descomprimir el archivo `.zip`.
2. Abrir la carpeta del proyecto.
3. Hacer doble clic en `index.html`.

No necesita instalacion ni servidor, porque esta hecho unicamente con HTML y CSS.
